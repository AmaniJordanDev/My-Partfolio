About Me

Home / About

Building Digital Experiences

I'm Amani Jordan, a self-taught front-end developer passionate about creating beautiful, functional web applications that solve real problems.

Based in Kampala, Uganda, I started my coding journey with a curiosity and determination to master web development. For the past 3+ years, I've been building responsive, user-friendly websites for schools, churches, startups, and small businesses.

My approach combines clean code, modern design principles, and a deep understanding of user experience. Every project is an opportunity to learn something new and deliver excellence.

When I'm not coding, you'll find me creating tech content for beginners, contributing to the developer community through my DevRise Community, or exploring new web technologies.
